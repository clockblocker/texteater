# Make Knowledge Reading-owned

Knowledge belongs only to one exact Reading; Lemmas never own Knowledge.
Transcription therefore lives in Reading Knowledge as one optional normalized
string, without a Target Language bucket or list. This is a hard break: tf-demo
discards incompatible data through full demo reset and Dumrel, Dumdict, and
tf-demo provide no Lemma-Knowledge migration or compatibility path.
