# Use Reading-owned, Lemma-targeted Semantic Relations

The default Semantic Relation mode stores a direct claim on one exact source
Reading and targets one exact Lemma. Generated Unit Shadows resolve to Lemmas
or remain pending. This keeps relation Knowledge Reading-owned while allowing
all Readings of the target Lemma to participate in deterministic projections.
ADR-0012 owns storage orientation and ADR-0016 adds exact-Reading target mode.
