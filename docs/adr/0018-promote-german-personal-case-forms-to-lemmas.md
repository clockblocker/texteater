# Give German pronoun coordinates grammatical identity

German PRON case, gender, possessor gender and agreement number were Core, so
every reviewed pronoun form was its own Lemma (`uns`/Acc and `uns`/Dat,
`seiner`/Masc and `seines`/Neut). Amendments between 2026-09-25 and
2026-09-28 confined per-cell identity to pillars, moved possessor features to
the Surface and settled referent-decided cells.

Superseded by [ADR 0044](./0044-identify-german-pronouns-by-pillar-stem-and-referent.md),
which states the current German pronoun decisions in one place.
