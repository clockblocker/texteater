# German Grammatical Resolution: 21-route migration matrix

Status: repository audit for [texteater#91](https://github.com/clockblocker/texteater/issues/91), child of [map #90](https://github.com/clockblocker/texteater/issues/90). This is a dispatch specification, not implementation. The source snapshot is commit [`8c46dd7`](https://github.com/clockblocker/texteater/tree/8c46dd7dd5b5c67b7b815b52304aef2f5aeba3f1).

## Contract shared by every row

Canonical Dumling entity schemas are generated by [`de-subtree.ts`](https://github.com/clockblocker/texteater/blob/8c46dd7dd5b5c67b7b815b52304aef2f5aeba3f1/battery/dumling/src/schemas/concrete-language/features/de/de-subtree.ts) through [`builders.ts`](https://github.com/clockblocker/texteater/blob/8c46dd7dd5b5c67b7b815b52304aef2f5aeba3f1/battery/dumling/src/schemas/shared/builders.ts). Every proposed model field below is therefore either an Attestation field from that builder (`memberOrthographies` projects to `Attestation.members[].orthography`; `normalizedMembers` projects positionally to `Surface.normalizedSurface`; Phraseme-only `realizationCoverage`) or a field of the row's canonical Lemma/Citation/Inflection codec. The accepted topology and projection rules are in [ADR 0003](https://github.com/clockblocker/texteater/blob/8c46dd7dd5b5c67b7b815b52304aef2f5aeba3f1/docs/adr/0003-attestation-supersedes-selection-and-owns-realization-coverage.md), [ADR 0004](https://github.com/clockblocker/texteater/blob/8c46dd7dd5b5c67b7b815b52304aef2f5aeba3f1/docs/adr/0004-align-german-high-level-targets-with-fixed-realized-attestation-members.md), and the [Dumling context](https://github.com/clockblocker/texteater/blob/8c46dd7dd5b5c67b7b815b52304aef2f5aeba3f1/battery/dumling/CONTEXT.md).

All 21 model DTOs have input exactly `{ markedContext: string, members: string[] }` and flat output:

```ts
{
  memberOrthographies: ("Standard" | "Typo")[];
  normalizedMembers: string[];
  realizationCoverage?: "Full" | "Partial"; // present only on Phraseme
  surface: ModelSurface;
  lemma: ModelLemma;
}
```

Code validates both arrays against ordered `members`; joins `normalizedMembers` with one space; constructs `Attestation.members[].attested` from the supplied members; injects `language: "de"`, Family, Kind, the Surface-to-Lemma link, and the successful resolution wrapper; normalizes `{ historicalStatus: null }` to `surfaceFeatures: null`; and injects `realizationCoverage: "Full"` for Lexeme and Construction. `Unresolved`, route classification, membership repair, confidence, candidates, target indices, normalized Surface scalar, and explanations are never model output.

Notation used in the matrix:

- `C` = Citation. Model Surface fields are `spelling: Canonical|Variant` and `surfaceFeatures: null|{historicalStatus: Archaic}`. Application injects `surfaceKind: Citation` because it is fixed for a Citation-only route.
- `C|I(F)` = Citation or Inflection. The model also emits `surfaceKind` as the discriminator; Inflection alone carries correlated `inflectionalFeatures: F`.
- Every listed Core Feature key is required in Structured Output and nullable unless shown otherwise. `Yes` means literal `"Yes"`.
- `Case4=Acc|Dat|Gen|Nom`, `Gender3=Fem|Masc|Neut`, `Number2=Plur|Sing`, `Degree3=Cmp|Pos|Sup`.
- `VerbF5` is the exact five-branch Dumling inflection union: (1) unspecified form `{number:Number2|null, tense:Past|Pres|null, verbForm:null, voice:Pass|null}` with at least one non-null; (2) imperative `Fin` (`mood:Imp`, null tense); (3) indicative/subjunctive `Fin` (`mood:Ind|Sub|null`, nullable number/person/tense/voice); (4) infinitive `Inf` (null mood/person/tense); (5) participle `Part` (nullable `aspect:Perf`, gender, number, `tense:Past|Pres`, `voice:Pass`, with null mood/person). Other keys in each correlated branch are the required nulls. The modern prompt may teach the four explicit-form branches first, but must not narrow the canonical codec's nullable ambiguity branch away.
- `PS`, `EX`, `GP`, `DOC`, `TEST`, and `CAT` mean `battery/dumgen/src/promptsmith/production/grammatical-resolution/de`, `battery/dumgen/src/promptsmith/laboratory/experiments`, `battery/dumgen/src/promptsmith/production/generated-system-prompt/grammatical-resolution/de`, `battery/dumgen/docs/prototypes`, `battery/dumgen/tests/internal`, and `battery/dumgen/src/catalog/laboratory/de-authored-grammatical-resolution-prompts.ts`, respectively.
- In “corpus”, `T/U -> +N` means T current Golden Case IDs, U obsolete `Unresolved` IDs, therefore at least N new valid-route cases are needed to leave 30 positive/total post-classification cases if none of the U cases can be reinterpreted. Reinterpreting a named same-route or Partial case can reduce `+N` one-for-one. Current retained runs are bound to the obsolete wrapper/input/corpus and are historical only; every row needs three fresh classified development rounds plus one untouched acceptance run.
- “Move membership” means retain the phenomenon only in Target Classification or deterministic input/alignment tests, not as a Grammatical Resolution Golden Case. “Delete route negatives” means the upstream classifier owns them.
