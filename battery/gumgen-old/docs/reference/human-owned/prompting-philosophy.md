# Prompting philosophy

DTOs and instructions may use English. The language code describes the text
being analyzed, not the language of the prompt.

Deterministic work belongs in code. Give each prompt one small judgment, the
minimum context needed for it, and no decisions already made elsewhere.

The prompt body states the big picture and high-level policy. Demonstrations
own the boundary cases.

Use an explanation only for a genuine edge case. Make it caveman-short.
