# Make the workspace own navigation

tf-demo uses `/` as its single application URL. Library, Text, and Note are
workspace subjects presented through the central Navigation Anchor, Panes,
Sheets, and transient Card Layers; Settings remains shell state. Placed Pane
and Sheet state is versioned browser storage, while Card Layers, drag sessions,
announcements, and Settings are transient. Resource URLs and route-encoded
workspace state are intentionally unsupported.
